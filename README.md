# Useless Superpower Line

Entry for make.fun's **"One Line, Zero Use: The Useless Superpower Sprint"** — one original line, at most 200 characters, naming a hilariously useless superpower.

> I can summon rain whenever I want — but only just after I've washed my car and left every window down.

## Run

```bash
python3 main.py
```

This writes the line to `/output/entry.txt`.
